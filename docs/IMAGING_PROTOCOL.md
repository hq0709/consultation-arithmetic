# 影像实验方案（锁定版，2026-10-19）

目标期刊：Meta-Radiology（结构化摘要 ≤250 词；APC 在 2026-12-31 前投稿免除）。
本文件在全量实验之前定稿。全量运行只执行这里写下的条件、指标和预设的备选方案；
pilot 和验证步骤的结果只用来在预设规则之间做选择，不新增条件。

## 1. 核心问题

**多个 AI 读片者为什么会在同一张片子上一起错？哪一种共享让它们失去独立性？**

放射科的双人阅片有效，前提是两位读者的错误互相独立。AI 读片小组里，读者之间共享
模型权重、视觉输入、题干先验、角色提示、参考病例，以及讨论记录。本研究逐一拆开这些
共享成分，测量每一种对错误相关的贡献。

pilot 已有的证据（gpt-5-mini，VQA-RAD，250 题，9 名读者）：
- 看原图 71.6%，看灰图 58.8%。看图改变了 38.2% 的答案。
- 读者-题目层面：先验对且看图仍对 46.8%，看图纠正先验 25.8%，看图带错 12.4%，先验错看图仍错 15.0%。
- ≥7/9 读者答错的 53 题中，30 题（57%）的多数答案与灰图下的多数答案相同。
- 错误相关 φ 原图 0.709，灰图 0.711（配对差 95% CI −0.060 至 +0.052）：看图改变答案，不改变错误相关。

## 2. 研究问题与预设预测

| | 问题 | 预测（任一结果都可解释） |
|---|---|---|
| RQ1 | 读片小组的正确与错误，有多少来自图像，有多少来自题干先验？ | 共识错误中相当一部分与灰图先验一致；φ 原图 ≈ φ 灰图 |
| RQ2 | 每一种共享成分对错误相关 φ 贡献多少？ | 换模型（跨厂商）降 φ 最多；换图像呈现与换角色降得少；讨论把 φ 推向 1 |
| RQ3 | 讨论（共识阅片）对比独立判读（盲法双读），会不会压掉"真正看对图"的少数读者？ | 看图得出正确答案的读者在讨论中改错的比例，不低于靠先验答对的读者 |
| RQ4 | 共享参考病例（多模态记忆）提高准确率，还是成为新的共同错误来源？ | 共享记忆提高单人准确率但推高 φ；私有记忆的 N_eff 更高 |

读者数量（N = 1、3、9）只作为起点的描述，不是主问题。

## 4. 模型（固定，Claude 一项按 V1 规则选定）

- OpenAI gpt-5-mini（effort=low）
- Google gemini-3.7-flash
- Anthropic：claude-sonnet-5 或 claude-haiku-4.5，经 OpenRouter。**选择规则**：V1 中单读者准确率
  更接近另两个模型均值的那一个；相差不到 3 个百分点时选 sonnet-5。

温度 0.7（推理模型忽略温度）；seed 1；图像长边缩至 1024 px。

## 5. 实验条件

除注明外 N = 9，独立判读，原图，放射亚专科角色。

| 代号 | 条件 | 规模（每模型每数据集） | 服务于 |
|---|---|---|---|
| C1 | 原图：单读者；Independent N=1/3/9；Decentralized N=3/9 | 已在 pilot 中完成 2 模型 × 2 数据集 | 全部 |
| C2 | 灰图（同尺寸纯灰，提示不变）：单读者；Independent N=1/3/9 | 同上 | RQ1、RQ3 |
| C3 | 通用角色（9 名读者提示完全相同，只差采样）：Independent N=9 | 9 次调用/题 | RQ2 基线 |
| C4 | 图像呈现：通用角色，读者 1–3 原图、4–6 反相、7–9 对比度增强（CLAHE） | 新增 6 次调用/题（原图 3 名与 C3 共用缓存） | RQ2 |
| C5 | 跨厂商：由 C3/C4 事后组合（3 家各 3 名；或厂商 × 呈现各不相同的 9 名） | 不新增调用 | RQ2 |
| C6 | 参考病例（仅 VQA-RAD、SLAKE）：无记忆 / 共享记忆（9 人同一组 3 例）/ 私有记忆（每人各一组 3 例）；外加带记忆的单读者 | 19 次调用/题，每次 4 张图 | RQ2、RQ4 |
| C7 | 讨论：Decentralized N=9（即 C1），轮次记录用于 RQ3 | 已在 C1 中 | RQ3 |
| C8 | SLAKE 成对题：单读者 + Independent N=9 | 400 题 × 10 次调用 | RQ1 |

**C6 参考病例库**：VQA-RAD 与 SLAKE 训练集的封闭题（图像 + 一个问答对）。剔除与测试图像
完全相同（哈希）或近似重复（CLIP 余弦 ≥ 0.95）的病例。检索：本地 CLIP ViT-L/14-336 图像
嵌入，取最近的 27 例，按 qid 固定随机打乱后分成 9 组、每组 3 例。共享记忆所有人用第 1 组，
私有记忆第 i 名读者用第 i 组。这样两种条件下参考病例的相似度分布相同，差别只在是否共享。

## 6. 指标与分析（预设）

- **O1 准确率**：比例，95% CI 用题目层面的 bootstrap（2000 次，seed 0）；配对差同样用 bootstrap。不报 p 值。
- **O2 错误相关**：φ = 各读者对之间错误指示变量的皮尔逊相关的均值（与文本论文同一定义，
  `experiments/independence.py`）；N_eff = 9 / (1 + 8φ)；跨能力的读者对另报 φ/φ_max。
- **O3 先验分解（C1 对 C2）**：读者-题目的 2×2 表（先验对/错 × 看图对/错）；
  共识错误（≥7/9 错）中多数答案与灰图多数相同的比例；φ 原图对灰图。
- **O4 成对题（C8）**：两题都对的比例；两题答案不同的比例（不看图的读者恒为 0）。
- **O5 独立性预算（C1、C3–C6）**：以读者对为单位回归
  φ_ij = β0 + β_厂商·[不同厂商] + β_呈现·[不同呈现] + β_角色·[不同专科] + β_记忆·[不同参考病例] + ε，
  报告每项的 Δφ 及题目 bootstrap 的 95% CI；讨论后的 φ（C7 末轮）作为"共享讨论记录"一项单列。
- **O6 讨论中的从众（C7 + C2）**：首轮答对的读者在末轮改错的比例，按首轮答案是否随图像改变
  （与该读者灰图答案不同）分两组比较；首轮答错者改对的比例同样分组。
- **O7 小组价值**：oracle（任一读者答对）、headroom（oracle − 单读者）、捕获率
  （改名为 capture rate C，避免与放射科常用的 Cohen/Fleiss κ 混淆）。

未解析出答案的意见计为答错（与文本论文一致）。

## 7. 全量运行前的验证步骤（约 $20–30）

| 代号 | 内容 | 通过标准与预设备选 |
|---|---|---|
| V1 | Claude 两个候选各跑 3 个数据集各 50 题单读者 | 解析率 ≥ 95%；按第 4 节规则选模型 |
| V2 | 三种呈现 × 三个模型 × 每集 50 题单读者 | 反相、CLAHE 的平均准确率距原图不超过 5 个百分点；不达标的那种换成 γ = 0.7 的亮度变换，不再另换 |
| V3 | 建参考病例库；目检 20 个检索结果；泄题检查；50 题共享记忆单读者 | 0 张相同图像进入参考病例；解析率 ≥ 95%，否则参考病例由 3 例减为 2 例 |
| V4 | 构建 SLAKE 200 对成对题 | 每对一题答"是"一题答"否" |
| V5 | φ 精度（pilot 已完成） | 单格 φ 的 SE ≈ 0.02，配对差可检出约 0.06；9 格合并约 0.02，满足 RQ2 |
