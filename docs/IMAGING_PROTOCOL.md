# 影像实验方案 v2（锁定，2026-10-20）

目标期刊：Meta-Radiology（结构化摘要 ≤250 词；2026-12-31 前投稿免 APC）。
本文件在全量实验前定稿。全量运行只执行这里写下的条件；验证步骤的结果只用来在预设
备选之间选择，不新增条件。v1（10-19）由本版取代。

## 0. 运行约定

- **所有 API 调用走 OpenRouter**（含路由器 gpt-4.1-nano）。结果文件前缀 `IMG2_`，与 pilot
  （`IMG_`，直连）分开；pilot 只作为设计依据，不进最终数据。
- Google 只用 Flash，不跑任何 Pro 模型。
- 温度 0.7（推理模型忽略）；seed 1；图像长边缩到 1024 px；同一实验格子内路由与 token 预算一致。

## 1. 核心问题

多模态读片的答案有两个信息来源：**图像证据**和**题干先验**。答案要经过两道工序：**看**（视觉编码器把图像变成特征）和**判**（语言模型把特征与先验合成答案）。多个 AI 读者一起错，说明它们在某个环节共享了瓶颈。本研究在每个环节上做干预，回答：**AI 读片小组的错误相关从哪里来，哪些设计能让读者真正独立。**

pilot 证据（直连，2 模型 × 2 数据集 × 250 题）：
- 9 名读者的错误相关 φ = 0.68–0.73，N_eff = 1.32–1.39；讨论后 φ = 0.99。
- 看图改变 25–41% 的答案；gpt-5-mini 的 φ 原图与灰图相同（VQA-RAD 0.709 / 0.711；MM 0.683 / 0.711）。
- 去图后准确率：VQA-RAD 掉 13–26 个百分点；MedXpertQA-MM 掉 7–14 个百分点（Gemini 灰图仍有 68.8%）。

### 实验 B：看与判分开（S1–S3）
| 代号 | 条件 |
|---|---|
| B1 | 每个写报告者（gpt-5-mini / gemini / haiku）对每张图写 9 份**不知道问题**的影像所见（≤120 词：模态与层面、所见解剖、所有异常及位置） |
| B2 | 答题者（同三家，通用角色）只看报告和问题、不看图答题。**独立报告**：第 i 名读者读第 i 份报告，3 写报告者 × 3 答题者全交叉。**共用报告**：9 名读者都读第 1 份报告，只在写报告者与答题者同一家时运行 |
| B3 | 参照：通用小组直接看图（C1） |

报告是否覆盖所问目标（仅 S2）：报告中是否出现该题器官或病灶的名称（同义词表在运行前由 SLAKE 标签生成并锁定）。

### 实验 C：独立性预算（S1–S3；记忆只在 S1、S2）
| 代号 | 条件 |
|---|---|
| C1 | 通用小组，原图 |
| C2 | 图像呈现：通用小组，读者 1–3 原图（与 C1 共享）、4–6 反相灰度、7–9 CLAHE 对比度增强 |
| C3 | 跨厂商：由 A0、C1、C2 事后组合，不新增调用 |
| C4 | 参考病例（S1、S2）：通用小组 × {共享, 私有} × {图像+问答, 只给问答文字}；另有单读者 × {图像+问答, 只给文字} |
| C5 | 讨论：主小组 Decentralized 9（即 A0） |

**C4 参考病例库**：VQA-RAD 与 SLAKE 训练集的封闭是非题图像。剔除与测试图像哈希相同或 CLIP 余弦 ≥ 0.95 的图像。
检索用本地 CLIP ViT-L/14-336 图像嵌入，取最近 27 张，按 qid 固定随机打乱后分成 9 组、每组 3 张。共享条件所有人用第 1 组，私有条件第 i 名读者用第 i 组。
每张参考图配一个问答：该图像所有封闭问答中，与当前问题 TF-IDF 余弦最高的一条。

### 实验 D：机制（本地 GPU，不花 API 费）
六个开源模型在 S1–S4 上逐题计算选项概率（选项字母的下一词元概率，提示固定，不采样）。条件：原图、灰图、256 px、128 px、S4 的遮目标与遮对照、反相、CLAHE。

## 7. 指标（预设）

- **准确率**：题目层面 bootstrap 95% CI（2000 次，seed 0）；配对差同法。不报 p 值。
- **φ**：读者对之间错误指示变量的皮尔逊相关的均值（`experiments/independence.py`）。
  另报 N_eff = 9 / (1 + 8φ)；能力不同的读者对另报 φ/φ_max。
- **A1**：各证据级别的准确率与 φ。共识错误（≥7/9 错）中，多数答案与灰图多数答案相同的比例。读者-题目层面的 2×2 表（先验对/错 × 看图对/错）。
- **A2**：翻转率 = 遮挡后答案与原图答案不同的比例；区域依赖 = 遮目标翻转率 − 遮对照翻转率（读者层面与小组多数层面）。
- **A3**：两题都对的比例；两题答案不同的比例（不看图的读者为 0）。
- **B**：写报告者 × 答题者的准确率矩阵。独立报告、共用报告、直接看图三者的 φ。S2 上把错误分为"报告没覆盖所问目标"与"覆盖了但答错"。
- **C**：以读者对为单位回归 φ_ij，自变量为两名读者是否同一厂商、同一呈现、同一报告、同一角色、同一参考病例组；讨论后 φ 单列。各项报告 Δφ 及 bootstrap CI。C4 另报各记忆条件的准确率。
- **讨论中的从众**：首轮答对者在末轮改错的比例，按首轮答案是否随图像改变（与其灰图答案不同）分组比较。
- **D**：视觉依赖度 VR = TV(p_原图, p_灰图)；区域依赖度 RR = TV(p_原图, p_遮目标) − TV(p_原图, p_遮对照)。
  模型间错误相关按"是否共用视觉编码器"分组比较。API 小组的共识错误题与开源模型 VR 的 Spearman 相关。
- 未解析出答案记为答错；捕获率改名 capture rate C，避免与放射科常用的 Cohen/Fleiss κ 混淆。

## 12. 运行记录（全量运行中）

- 2026-10-19：claude-haiku-4.5 在灰图条件下常拒绝作答（"the image appears to be completely blank…"）。VQA-RAD 单读者 41/250（16%）、SLAKE 12/250、MedXpertQA-MM 35/250 无法解析。
  - 按第 7 节，未解析的答案记为答错，并另报各条件的拒答率（结果行中的 `abstain`）。
  - 输出质量中止（`BAD_OUTPUT_ABORT`，默认 15%）是为发现配置错误而设，拒答属于模型行为，因此灰图条件关闭该中止。被它中途截断的格子写入 `IMG2_<model>_<set>_fix.jsonl` 补齐；分析时与主文件合并并去重。
  - 先验分解中，灰图下拒答的读者视为"先验错"（与"未解析记为答错"一致）。
- 2026-10-19：实验 B 的报告预写。报告的缓存键只含感知模型、图像与槽位，同一图像的所有问题、所有推理模型共用。若在 B 中边读边写，两个 worker 同时遇到同一图像时会各自调用感知模型，缓存以后写者为准，于是不同推理模型可能读到同一槽位的不同报告，"同报告、不同推理模型"的读者对就不再成立。
  - 因此在任何推理模型读报告之前，先用 `experiments/write_reports.py`（`scripts/write_reports.sh`）为三个感知模型各写 478 张图像 × 9 个槽位的报告；调用与 `arch_report` 是同一个函数（`write_report`），验证时 V5 已有的 3 × 57 份报告全部命中缓存。
  - 预写期间暂停 gpt-5-mini 与 claude-haiku-4.5 的总控脚本，使其在 C4 结束后不进入 B；正在运行的格子不受影响。gpt-5-mini 的报告写完后恢复。
- 2026-10-19：实验 C 回归的编码（在任何 B 数据之前确定）。
  - 每名读者的属性：看图模型（perceiver）、答题模型（reasoner）、输入（原图或报告）、呈现、角色、参考病例组、报告样本。直接看图的读者，看图模型与答题模型相同。
  - 每个答题模型对各设一个截距：同模型对的截距是两名配置完全相同的读者之间的 φ，跨模型对的截距是看图模型相同时的 φ。其余为"不共享"指示变量：不同看图模型、原图对报告、不同呈现、不同角色、不同参考病例组、不同报告（仅当两名读者都读报告）。"不同答题模型"的效应 = 跨模型截距 − 两个同模型截距的均值。
  - 原因：各模型自身的 φ 差异很大（A0 中 qwen3.8-flash 0.42–0.65，其余 0.69–0.84）。合并截距或按模型可加的截距，都会把模型差异混进各成分的效应（试算时 qwen 的基线被拟合成 0.68，实际为 0.42）。
  - 另报每个"答题模型对 × 不共享成分"组合的原始平均 φ 及 bootstrap CI。
  - 删除原规则"属性完全相同且非通用角色的读者对剔除"：它会误删共用报告格子内的读者对，而这些正是"同一报告、只差采样"的读者对。
- 2026-10-19：讨论中的从众（第 7 节）另按读者首轮答案是否属于首轮多数分层，并报告首轮答对者中处于少数的比例。
- 2026-10-19：每个 bootstrap 区间使用各自的随机数生成器（seed 0），区间不随分析顺序改变。
- 2026-10-19：报告预写完成：三个感知模型各 4,302 份（478 张图像 × 9 个槽位），全部非空；各有 4/8/24 次瞬时错误，重跑后补齐。字数中位数 / 最大值：gpt-5-mini 75 / 118，claude-haiku-4.5 75 / 121，gemini-3.7-flash 90 / 127（提示要求 ≤120 词；如实报告实测最大值）。
